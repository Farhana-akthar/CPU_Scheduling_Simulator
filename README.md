# CPU Scheduling Simulator

A simple **CPU Scheduling Simulator** implemented in Python to demonstrate different CPU scheduling algorithms like **FCFS, SJF, Priority Scheduling, and Round Robin**. This project is useful for students and beginners to understand how CPU scheduling works in operating systems.

## Features

- First-Come-First-Serve (FCFS)
- Shortest Job First (SJF)
- Priority Scheduling
- Round Robin (RR)
- Calculates waiting time, turnaround time, and completion time for each process
